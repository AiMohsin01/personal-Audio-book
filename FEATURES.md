# Implementation checklist

This is working application code, not a static mockup. It does **not yet implement every advanced feature in the original specification**. Status below distinguishes implemented functionality from unverified integrations and remaining work. There are no fake books, synthetic dashboard statistics, disabled premium features, or hidden paid services.

| Area | Implemented | Qualification / remaining work |
|---|---|---|
| Stack | React + TypeScript, Vite, Tailwind, Lucide, IndexedDB, HTML Audio, SQLite companion, Media Session, service worker | Production build required for offline app shell; actual browser/OS support varies |
| Dashboard | Empty-state introduction, real book/in-progress/completed counts, continue listening, recently added | No fabricated activity or sample library |
| Upload | Multiple files, file picker, drag/drop, import progress, SHA256 duplicates, PDF/EPUB/audio metadata, embedded covers, custom covers | WAV/PDF/EPUB imports browser-tested; MP3/FLAC codec support is browser dependent |
| Audio formats | MP3, M4B, WAV, FLAC, M4A, OGG Blob storage | Actual playback depends on installed browser decoder; a decode error is reported |
| Book details | Title/author/description/category editing, favorite, completion, collection assignment, deletion, original export, replacement | Replacement resets chapter progress/notes to avoid dangling positions |
| Chapters | EPUB spine chapters, PDF pages, embedded M4B/MP4 chapters, editable titles/text, adding text chapters, reordering/removal, source-audio splitting with note remapping | Nero lists read independently of audio; metadata parser supports some QuickTime chapter tracks. Original PDF outline chapters and MP3 ID3 chapter frames are not yet supported. |
| Library | All/current/recent/completed/favorites, custom collections, author/genre filters, search, grid/list, title/author/added/played/duration/progress sorting | One collection per book; advanced multi-collection rules and arbitrary custom metadata schemas remain work |
| Player | Play/pause, seeking, skips, speed, chapter navigation, remaining time, volume, time/end-chapter sleep, playback queue, remembered position, restore last book, smart rewind, bookmarks, timestamped notes, keyboard shortcuts | Automatic audible autoplay is avoided until user action. Silence detection is opt-in using actual RMS signal energy; thresholds need tuning for quiet speech. Cross-browser background/lock-screen support is not promised |
| Reader | PDF/EPUB extracted text, chapter navigation, font/font size/spacing, paper/light/dark backgrounds, scroll persistence, book search, reading bookmarks, selected highlights, browser live reading | Not original PDF page rendering or EPUB styling; highlighted selection is visible when it fits inside a sentence. Live speech highlights current sentence, never fake word timings; exact generated-audio text synchronization is not implemented |
| Voice Studio | Local companion connection, installed voices, preview, per-book voice, speed, real chunk progress, chapter WAV generation, pause/resume/retry, duplicate jobs, export, generated-book playback | Actual export tested with eSpeak on Linux. Piper engine is installed and integrated, but neural inference cannot yet be validated without a model. Browser speech is only live reading |
| Neural voices | Explicit size/RAM disclosure, upstream model-card consent, model SHA256 validation, optional downloads, additional local .onnx/config/license files | Hugging Face is blocked in current cloud runtime; draft contains needed domains. Catalog model licensing must be reviewed from upstream card. No neural model is preinstalled or downloaded silently |
| Voices & languages | English male-style/female-style eSpeak variants; language/gender labels on installed Piper/custom models | Additional languages require compatible user-installed models. eSpeak is a robotic fallback, not “AI” quality. Piper package support and eSpeak bridge portability depend on OS |
| Scanned PDFs | Image-only text limitation explained; free OCRmyPDF/Tesseract command documented | OCR is external preprocessing, not an in-app engine; optional dependencies not installed or tested here |
| Customization | Theme/accent/background/font/size/card size/cover height/density/sidebar width/compact player; playback defaults/volume/skip/speed/rewind/sleep/resume/voice; sorting/listening goals; reader typography/background; companion URL; reset per settings category | Arbitrary sidebar skin, custom player arrangements, configurable metadata schemas, and every possible layout preference are not implemented |
| Statistics | Actual elapsed audio listening time, daily chart, weekly/monthly/all-time totals, listening streak, daily goal, completed status count, per-book progress, playback history | Reader/live-speech duration is not counted. Completion flags can be manually set; the UI explains this. No estimated listening values presented as measured |
| Storage | Usage/quota estimate, persistent-storage request, original files retained, full JSON backup/restore, metadata export, cache clearing, book deletion, generated-audio clearing | Multi-gigabyte browser backups require too much memory. Companion files/models/jobs need filesystem backups and manual disk management; no service storage-management UI yet |
| Offline/privacy | No account/ads/trackers/paid APIs; app and PDF worker precache; local books/notes/progress/settings; local-only companion defaults; Host/Origin/path validation; no book requests to cloud | First app installation and dependency/optional voice downloads need network. Browser OS speech may require network. Unconfigured mobile-to-desktop companion access is not supported |
| Performance | Chunked hashing, asynchronous EPUB decompression, PDF worker/page extraction, lazy-loaded views, bounded synthesis chunks, persisted WAV files, streamed chapter assembly, one cached neural model | EPUB expansion limited to 512 MB for memory safety. Full browser PDF/EPUB text and backup serialization still need memory; filesystem-backed streaming import and huge-library virtualization remain work |
| Accessibility | Semantic buttons/headings/labels, focus outlines, touch-sized primary controls, keyboard playback, live notifications, reduced-motion support, mobile navigation | No claim of a full WCAG audit or screen-reader certification; manual assistive-technology testing remains work |
| Testing | Production TypeScript build; library/backup/chapter unit tests; real companion speech tests; browser import/playback/persistence/reader/conversion/backup/offline/mobile tests; runtime errors collected | Neural voice installation/inference, OCR, every codec/platform, full keyboard/screen reader access, large-library stress, and mobile companion networking remain unverified |

All 12 requested screens are represented: Dashboard, Library, Upload, Details, Player, Reader, Voice Studio, Bookmarks/Notes, Insights, Collections, Settings, and Storage. Visible controls perform actual actions; unavailable operations are disabled with their prerequisite explained.

## Priorities remaining before calling this feature-complete

1. Enable model-host access, check exact model cards/licenses and integrity, install a consented voice, validate Piper generation and performance.
2. Add a filesystem-backed large-book import/backup path, service disk/model/job management, and large-library stress testing.
3. Expand PDF outline handling, rich layout reading, cross-sentence highlights, and generated-audio timing where the engine supplies real alignment.
4. Add in-app OCR if desired, additional customization schemas, multi-collection organization, and reader activity tracking.
5. Validate mobile HTTPS companion access, browsers/codecs/OS background playback, accessibility, and cross-platform packaging.
